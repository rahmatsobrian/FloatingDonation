Changelog Rule

- Selalu baca "changelog.md" sebelum mulai mengerjakan perubahan pada project.
- Setiap kali perubahan, perbaikan, penambahan fitur, atau pekerjaan selesai, wajib update "changelog.md".
- Changelog terbaru HARUS ditulis di baris paling atas.
- Jangan menaruh changelog terbaru di bawah changelog lama.
- Pertahankan changelog lama, jangan dihapus atau diubah tanpa alasan.
- Gunakan format sederhana dan ikuti format yang sudah ada di "changelog.md".
- Jika tidak ada perubahan pada file project, tidak perlu menambahkan changelog.

Format

Gunakan format:

Nomer

Tanggal-Bulan-Tahun-Jam-WIB

- Deskripsi perubahan.

Contoh:

3

12-09-2026-1645-WIB

- Memperbaiki tampilan Dashboard.

2

11-09-2026-1630-WIB

- Memperbaiki tampilan Dashboard.

1

10-09-2026-1600-WIB

- Memperbaiki tampilan Dashboard.

Selalu gunakan urutan terbaru → terlama.

Wajib

Setelah menyelesaikan pekerjaan yang mengubah project:

1. Update "changelog.md".
2. Tulis perubahan terbaru di paling atas.
3. Gunakan nomor berikutnya dari changelog terakhir.
4. Gunakan waktu WIB (UTC+7).
5. Jangan menghapus changelog sebelumnya.
6. Pastikan "changelog.md" sudah tersimpan sebelum menyatakan pekerjaan selesai.
